PDFGenius

Simple, intuitive PDF manipulation for macOS. Merge, split, convert, and refine documents while preserving structure, fonts, colors, links, and bookmarks. Version 4.16, optimized for the latest macOS.

Merge & Split

Combine multiple PDFs into one, grouping outlines seamlessly. Split large files by pages, size (up to 50 MB per file), or top-level outlines—with titles as filenames.

Convert & Extract

Batch convert PDFs to JPG, JPEG2000, PNG, PSD, TIFF, or BMP. Extract pages for reuse, insert from other PDFs or images, add blank pages, delete blanks, rotate, and reorder via drag-and-drop.

Secure & Optimize

Add or remove passwords, edit metadata (title, author, subject, keywords). Apply page transitions, remove links from pages or entire documents, and optimize for fast web view.

Create & Refine

Generate PDFs from images, screen captures, windows, or selections. All operations maintain document integrity without quality loss.

How It Works

1. Drag & Drop

Select PDFs or images and drop them into the intuitive interface. Preview pages instantly in the browser view.

2. Choose Operation

Merge, split, convert, reorder, secure, or optimize. Fine-tune options like split criteria or output formats.

3. Process Batch

Apply changes to single files or batches. Watch progress with real-time previews and integrity checks.

4. Export Seamlessly

Save optimized PDFs directly. Everything preserves original quality, ready for use or sharing.
